# DexCeed VPN 1.0.1

Доведено брендирование DexCeed VPN: сборка qThroneMobile 3.3.0 с пакетом `online.dexceed.vpn`, своей иконкой и обновлениями из релизов DexCeed VPN.

- Диалоги, уведомления и подсказки во всех языках называют приложение DexCeed VPN. Названия формата резервных копий и ссылок qThrone сохранены для совместимости с qThrone Desktop.
- Из экрана «О программе» убрана ссылка на сайт исходного проекта.
- Адаптивная иконка получила прозрачный передний план: на круглых и фигурных масках больше нет тёмного квадрата.
